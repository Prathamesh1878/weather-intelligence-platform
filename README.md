# Weather Intelligence Platform 🌦️

## Overview

Weather Intelligence Platform is a web-based application that provides real-time weather information for any location. The platform integrates weather and geolocation APIs to display current weather conditions, temperature, humidity, wind speed, and other essential weather metrics through an interactive and user-friendly dashboard.

## Features

* Real-time weather data retrieval
* Location-based weather tracking
* Search weather by city name
* Interactive map integration
* Temperature, humidity, and wind speed monitoring
* Responsive and modern user interface
* Error handling for invalid locations
* Dynamic weather updates using external APIs

## Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/weather-intelligence-platform.git
```

2. Navigate to the project directory

```bash
cd weather-intelligence-platform
```

3. Install dependencies

```bash
npm install
```

4. Create a `.env` file and add your API keys

```env
OPENWEATHER_API_KEY=your_api_key
MAP_API_KEY=your_api_key
```

5. Start the application

```bash
npm start
```

6. Open your browser and visit

```bash
http://localhost:3000
```
